enum ManagerState

Defines all possible states of operation for the mobile platform.

Enumerator
STANDBY 

Rover is not performing any actions that could break communication.

MOVING 

Rover is changing position using engines.

SCANNING 

Rover is gathering environmental data, can't move now.

UPLOADING 

Rover is uploading data to PC.

STATUS_UPDATE 

Another state for uploading to controller.

IMU_CALIBRATION 

Rover is basically in idle state but imu is calibration mode.

PLATFORM_SETUP 

PLatform setup mode. User is able to setup some global proerties via UART commands.
