Detailed Description

Class handles calculation of position with respect to starting position of a 2 wheeled robot. Odometry is calculated based on patterns derived in here: .

Warning
The theta parameter is currently set based on data provided from an IMU sensor. It can be calculated purely from wheel rotations data but currently is not.
Todo
Provide some way to switch between ways of calculation of the theta parameter.
