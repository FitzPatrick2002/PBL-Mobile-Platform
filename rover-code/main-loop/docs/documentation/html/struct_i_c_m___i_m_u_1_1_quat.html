Detailed Description

Represents a rotation quaternion. To create a quaternion only q1, q2 and q3 are required. q0 will be calculated from them. Values q1, q2 and q3 can be freely modified and its programmers responsibility to make sure they fulfill the rotation quaternion requirements (q0^2 + q1^2 + q2^2 + q3^2 == 1).
